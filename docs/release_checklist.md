# Publication gate

This task authorizes local preparation only. No GitHub repository, push, release, or external file sharing has been performed.

Before public release, the owner must:

1. Select the project LICENSE and copyright holder spelling; verify any coauthor/institution conditions. Ownership and publication permission for the original team code were asserted by the owner on 2026-09-23; no license was chosen by the assistant.
2. Resolve NYC scene authorship, license, version and legal acquisition URL, or publish instructions for an approved replacement and identify changed experiments. Do not add the ignored private scene to Git without clearance.
3. Confirm bibliographic provenance of the embedded legacy parameter tables and the intended standards/version statements. Their approximate entries and model deviations remain clearly labeled; this is not a standards-conformance certification.
4. Identify paper title, authors, conference, DOI/preprint URL (if any), figure/table-to-experiment assignments, intended ensemble sizes and statistical acceptance criteria. These remain TBD.
5. Review the preserved research issues: C_tau convention, approximate correlation, scalar RT phase treatment, mixed light speed, Doppler direction, lack of full Hybrid spatial consistency and unsupported mode/TLE blocks.
6. If redistributing OpenNTN source rather than depending on it, resolve its MIT root/Apache-marked file scope, retain all applicable notices and record modifications. It is not currently vendored.
7. Supply a real Git author identity if commits are desired and none is configured. Never invent one. Review the explicit staged-file and secret/license scan reports before committing.
8. Review validation limitations and expand clean-system/hardware testing before claiming broader platform support or complete paper reproduction.

The default distribution set is the Git allowlist inside `repo/`. Sibling private_audit, original source snapshots, raw file-access logs, data/external, venvs and runs are **not** public deliverables. No whole-workspace archive should be published.
